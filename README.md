# Tray

A small floating inbox for macOS. Jot things down with ⌃⌥N; check them off when done.

This repository only hosts downloads. Grab the latest **Tray.zip** from [Releases](../../releases/latest).

## Install

1. Download **Tray.zip** and double-click it to unzip.
2. Drag **Tray** into your Applications folder and open it.
3. The first time, macOS will say it can't verify the app. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway**.

Requires macOS 26 or later (Apple Silicon or Intel).

## Update

Download the newest Tray.zip and replace the app in Applications. Your items are stored separately and are kept.
